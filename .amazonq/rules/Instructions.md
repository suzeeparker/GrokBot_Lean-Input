# Shell & Execution
- ALWAYS run scripts using Git bash: `bash -c "..."`
- Git bash is located at: `C:/Program Files/Git/usr/bin/bash.exe` and is on PATH as `bash`
- NEVER use `cmd /c` or PowerShell to run node scripts
- NEVER use backslashes in paths passed to `executeBash` — they get stripped
- ALWAYS use forward slashes `/` in all paths inside `bash -c "..."` commands
