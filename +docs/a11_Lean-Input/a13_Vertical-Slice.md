The earlier notes that say not to open a pull request, and that say the owner must merge by hand, are the prompts from before this slice was approved. Current rules are in `docs/lean-input/lifecycle.md` and `CONTRIBUTING.md`. A pull request may be open during development. It stays unmerged until the parent confirms both the real Grok Bot app acceptance and the Mac Cursor acceptance. After that confirmation the coding agent may merge. Linux tests are not that confirmation.
