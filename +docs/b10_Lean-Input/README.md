# Lean Input

`+skills/b10_lean_input/scripts/` is the canonical helper source for scraper-viewer. It is a template for a later tool. It is not installed, and a delivered bot or mac folder does not import it.

Shared edits are copied into `+skills/b11_scraper-viewer/bot/` and `mac/` by `+skills/b00_packaging/scripts/sync_platform_copies.py`. Operator documentation is `+docs/b11_Scraper-Viewer/`. The extractor library is Trafilatura.
